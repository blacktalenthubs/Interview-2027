# Interview-2027 — Staff-Level Interview Preparation

Owner: Olusegun Bolofinde · Target: Senior/Staff backend & platform roles (AI infrastructure, distributed systems, payments platforms) · Horizon: through April 2027

## The 4 layers

| Layer | Folder | What "ready" means |
|---|---|---|
| 1. Resume depth & project readiness | `01-resume-depth/` | Every project on the resume can be defended for 30 minutes: architecture, hardest decision, trade-offs, numbers, failure modes |
| 2. System design (Staff level) | `02-system-design/` | Lead a design end-to-end: requirements, estimation, API, data model, deep dive, trade-offs, evolution |
| 3. LeetCode 50 | `03-leetcode/` | 50 pattern-curated problems, each solved twice (once learning, once timed) |
| 4. Behavioral / Staff signals | `04-behavioral/` | STAR story bank covering ownership, ambiguity, conflict, cross-team influence, failure |

Progress lives in `tracker.md`. Rule: a checkbox is earned by doing, not reading.

## Weekly rhythm (suggested)
- 2 project-defense sessions (Layer 1/4 share source material)
- 2 system-design sessions (one new design, one redo)
- 5 LeetCode problems (spaced repetition on misses)
- 1 mock or out-loud self-recording per week
